# Архитектура — черновик

CONFIRMED: отдельная Ubuntu-машина в LAN, один NIC, самостоятельные backend/Web UI, отсутствие программной интеграции с роутером. Xray-core — основной кандидат.

UNDER_RESEARCH: forwarding, policy routing, nftables, TProxy/REDIRECT/TUN, TCP/UDP, DNS, IPv4/IPv6, обратный маршрут, обход перехвата собственными соединениями движка, петли, утечки, отказ Xray и восстановление доступа. Доставка маршрутизируемого пакета на Ubuntu сама по себе не передает его Xray. Механизм перехвата не выбран.

PROPOSED: отделить доменные настройки от генератора конфигураций движка и привилегированной сетевой интеграции; конкретные границы уточнить после исследования. Возможность sing-box в будущем не означает его реализацию сейчас.

OPEN_QUESTION: стек backend/frontend, хранилище, Core Manager, управление процессом, проверка конфигураций, мониторинг, установка/обновления, применение/откат. Системных изменений не выполнялось.

Сначала сценарий прохождения трафика и охват клиентов, затем DNS/IPv6 и отказ/применение; механизм перехвата выбирать после сравнения вариантов.
