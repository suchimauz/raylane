## D-008 — CONFIRMED: публичная готовность и небольшие коммиты
Возможна будущая публичная публикация. Персональный контекст тестирования/развертывания исключается из Git; конкретные хосты и учетные записи не являются спецификацией продукта. Локальные заметки отделены от общих документов. Коммиты — небольшими логическими шагами, Conventional Commits, с просмотром staged diff. Push/публикация не разрешены. Данные предоставленного стенда записаны только в игнорируемые локальные заметки; адрес требует уточнения до подключения.

## D-009 — CONFIRMED: все шесть транспортов VLESS

## D-010 — CONFIRMED: VLESS только с TLS или REALITY
Пользователь выбрал TLS и REALITY. Для первой версии режим VLESS без TLS/REALITY не разрешать, даже если PassWall его допускает. Это согласованное ограничение относительно референса, не новый default для каждого транспорта. Все шесть транспортов остаются выбранными (D-009), но совместимость каждого с TLS/REALITY должна подтверждаться целевой версией Xray; при невозможности безопасного сочетания требуется обсуждение, а не молчаливое снятие защиты или исключение транспорта. Flow/Vision пока OPEN_QUESTION.

## D-011 — CONFIRMED: все три значения VLESS flow
Сохранить пустое значение (выключен), xtls-rprx-vision и xtls-rprx-vision-udp443, как в PassWall. Не подменять выбранный режим автоматически; требуется совместимость сервера, транспорта и защиты. Выключенный flow не отменяет обязательность TLS/REALITY (D-010).

## D-012 — CONFIRMED: несовместимый узел сохраняется только как черновик
Разрешено сохранять несовместимые настройки узла как невалидный черновик с точной ошибкой; применение запрещено до исправления. Не менять автоматически транспорт, flow или защиту. Импорт не должен обходить запрет применения. Правило не утверждает саму функцию импорта. Сохранение не означает успешную проверку или применение; поведение уже действующей конфигурации при редактировании еще уточняется.

## D-013 — CONFIRMED: отдельное явное применение
Сохранение изменений узла, включая валидные, не меняет работающую конфигурацию. Текущая конфигурация продолжает действовать до отдельной команды пользователя «Применить» после проверки. Невалидный черновик применить нельзя (D-012). Бесшовность переключения, механизм перезапуска и автоматический откат при неудачном применении пока не утверждены.

## D-014 — CONFIRMED: XHTTP Extra и FinalMask для VLESS
Сохранить оба расширенных JSON-редактора с пояснениями, проверкой JSON и совместимости движка. XHTTP Extra относится к XHTTP; FinalMask заменяет автоматически собранный объект, а не объединяется с ним. Выбор не разрешает обход TLS/REALITY, автоматическое применение или применение невалидного черновика. Не распространять решение автоматически на другие протоколы. Точная политика сохранения невалидного JSON и скрытых значений пока открыта.

## D-015 — CONFIRMED: сохранять только синтаксически верный JSON
Для XHTTP Extra/FinalMask синтаксическая ошибка блокирует сохранение, не только применение. Неверный текст остается в редакторе до исправления, долговременное сохранение такого текста не гарантируется. D-012 продолжает действовать для синтаксически корректных, но несовместимых настроек: можно сохранить невалидный черновик, применять нельзя. Предыдущее сохраненное и активное состояние при ошибке сохранения не изменяется. Автоматическое исправление JSON не согласовано.

## D-016 — CONFIRMED: сохранять неактивные значения, исключать из генерации
При смене транспорта/режима или отключении расширенной настройки сохранять прежние значения для возврата, но не передавать неактивные настройки движку. Активность определяется семантикой режима и зависимостями, не простым скрытием раздела «Расширенные». Это согласованное правило приложения; точное совпадение с lifecycle LuCI не заявляется. Сохранение требует синтаксически корректного JSON (D-015), применение остается отдельным (D-013). Нельзя активировать неактивные значения ради обхода проверки совместимости.

## D-017 — CONFIRMED: исследованный расширенный набор защиты VLESS

Поля доступны по зависимостям соответствующих режимов, с пояснениями и проверкой совместимости целевого Xray/сервера. Не включать автоматически. Решение не разрешает отключение проверки сертификатов и не означает автоматическое включение будущих полей PassWall или перенос этого выбора на другие протоколы.
