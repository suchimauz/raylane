# Проект: независимая альтернатива PassWall

Черновик Discovery & Specification. Не финальная спецификация.

## CONFIRMED
- Цель: снять обработку прокси-трафика с ограниченного по ресурсам роутера и перенести на отдельную Ubuntu-машину в LAN.
- Один физический сетевой интерфейс первоначально.
- OpenWrt остается основным роутером; пользователь вручную направляет трафик на Ubuntu.
- Приложение независимо от OpenWrt: никаких API, LuCI, SSH-интеграции или автоматической настройки роутера. Источник трафика не определяет бизнес-логику.
- Собственные backend и современный Web UI. PassWall — поведенческий, не визуальный референс.
- Xray-core — основной кандидат первой реализации; не реализовывать сразу два движка.
- Точность настроек выбранных функций обязательна; отклонения согласуются с пользователем.
- Apple Design Skill обязателен.
- Только исследование и документация. Запуск агентов, разработка и сетевые изменения запрещены без разрешения.

## OPEN_QUESTION
Набор транспортов и расширенных функций, стек, механизм перехвата, IPv6 и политика отказа.

Подтверждено позднее: референс — современный PassWall, не PassWall2; выбранные подключения VLESS, SOCKS, HTTP-прокси и WireGuard. Допускается будущая публичная публикация: персональные данные стенда исключаются из Git. Небольшие локальные Conventional Commits разрешены; push не разрешен.
