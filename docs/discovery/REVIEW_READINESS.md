# Готовность к обсуждению выбранных подключений

## Артефакты
- PROJECT_OVERVIEW.md и DECISIONS.md: актуальный подтвержденный контекст.
- NODE_FIELD_INVENTORY.md: точные объявления обычной Xray-формы и отдельного Socks, common и chain-поля; defaults/validators/depends/handlers с permalink.
- SETTINGS_REFERENCE.md: нормализованная семантика четырех выбранных подключений, transport/security, общий слой, mapping Xray, особенности импорта и runtime defaults.
- PASSWALL_RESEARCH.md: источники и commits, отделение исследования UI от engine.
- CONNECTION_GAPS.md: 12 выявленных расхождений/рисков, продуктовые вопросы и технический долг исследования.
- ../../specs/001-selected-connections/spec.md: DRAFT NOT APPROVED, сценарии и измеримые предложенные критерии приемки.

## Документальная проверка
Проверено наличие ссылочных документов, ключевых полей всех четырех подключений и absence известных локальных адресов/имен/путей в предназначенных для Git файлах. При проверке найден пропуск вложенного chain-блока в механическом инвентаре; исправлен добавлением исходного блока. Проверка whitespace — git diff --cached --check перед коммитами.

## Границы результата
Готов материал для обсуждения, НЕ полная утвержденная исполнимая спецификация. Полнота инвентаря ограничена выбранными UI-блоками и перечисленными импортными путями; не утверждается полнота всех исторических форматов, LuCI framework defaults и runtime-валидации Xray. Эти пробелы перечислены, а не замаскированы предположениями. Для строгой финальной полноты нужны отдельная версия LuCI и целевой релиз Xray, трассировка импортов и разрешенные тесты. Ни продуктовые тесты, ни сборка, ни сетевые проверки не выполнялись. Статус runtime acceptance: NOT_RUN.

Исследование остальных разделов PassWall и сети Ubuntu остается отдельной работой. Пользовательские решения по scope/совместимости необходимы перед утверждением ТЗ, но не препятствуют дальнейшему чтению исходников. Агентам задания не передавались; разработка и push не выполнялись.

Устаревшие верхнеуровневые вопросы исправлены в матрице, CONNECTION_GAPS и основной спецификации; исторические уточнения сохранены. Это документальная сверка, не runtime-приемка и не разрешение разработки.
