# UI/UX — черновик

CONFIRMED: Apple Design Skill, современный самостоятельный UI вместо копии LuCI; читаемость и безопасность важнее эффектов, клавиатура/мышь/touch, доступность и reduced motion.

Прочитан полный установленный skill: docs/skills/apple-design/SKILL.md в установленной среде harness. Запрошенный upstream: https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md . Использована установленная копия, идентичность текущему upstream не проверялась.

PROPOSED для сетевой панели:
- Спокойная иерархия, системный шрифт, последовательные отступы, явные названия разделов.
- Основные и расширенные поля с контекстными пояснениями; расширенность не должна удалять семантику настроек.
- Различать редактируемое, сохраненное и реально примененное состояние. Мгновенная обратная связь на нажатие не должна изображать успех сетевой операции до подтверждения backend.
- Проверка и предварительный просмотр изменений, явное применение и восстановление — только предложения, требуют согласования.
- Короткие прерываемые переходы панелей, стабильное положение элементов; не блокировать ввод ради анимации. Прерываемость анимации не означает отменяемость системной операции.
- Цвет дополнять текстом/иконкой; видимый фокус, доступные подписи и ошибки, масштабирование текста.
- Полупрозрачность только там, где сохраняется контраст; solid fallback. Reduced motion: статические переходы/мягкая смена прозрачности без пружин.

OPEN_QUESTION: обе темы, состав навигации, визуальная диагностика, организация редактора правил. UI и прототипы не реализованы.

CONFIRMED D-012: несовместимый узел можно сохранить как явно невалидный черновик с объяснением ошибки; применять его нельзя. Сохранение, валидность и применение — разные состояния. Не исправлять настройки автоматически.
CONFIRMED D-013: отдельные действия «Сохранить» и «Применить»; сохранение не влияет на активную конфигурацию. UI различает сохраненные и примененные параметры, не изображает сохранение как применение. Переключение без разрыва соединений и автоматический откат пока не обещаны.
CONFIRMED D-015: синтаксическая ошибка JSON блокирует сохранение XHTTP Extra/FinalMask. Показать ошибку и оставить введенный текст для исправления, не заменяя предыдущую сохраненную версию. Корректный по синтаксису, но несовместимый JSON может сохраняться как невалидный черновик (D-012).
CONFIRMED D-016: смена режима сохраняет неактивные значения для возврата, но они не участвуют в генерации. Объяснять различие между неактивной настройкой и просто свернутым расширенным разделом; при возврате проверять совместимость заново.
CONFIRMED D-023: при попытке удаления используемого узла показывать список сохраненных и активных зависимостей, блокировать удаление до их устранения. Явно объяснять, когда сохраненные изменения еще нужно применить для удаления активной ссылки.
CONFIRMED D-026: редактор подписочного узла явно предупреждает, что обновление подписки заменит ручные изменения подписочных параметров. Не обещать сохранение overrides; сохраненное и активное состояние по-прежнему различаются.
CONFIRMED D-036: настройка отключения проверки сертификата HTTPS-подписки явно обозначена как опасная, выключена по умолчанию и действует только для данной подписки. Показывать предупреждение и состояние исключения, не предлагать его как автоматическое исправление сетевой ошибки.
